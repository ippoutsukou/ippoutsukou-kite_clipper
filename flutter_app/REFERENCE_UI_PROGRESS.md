# 参照画像に合わせた外観調整

利用者添付の04_preview.pngを直接確認して実施。複数候補・タグ・結合機能は対象外。

## 実装
- タイムラインの選択範囲外を暗くし、選択範囲を青い枠と縦線で表示。
- 時刻目盛りを追加。低い画面はラベルを省略して従来の高さを維持。
- PC一覧幅を画面幅の24%（260〜360px）にし、サムネイルを96×60へ拡大。
- 画面タイトルを太字・濃紺へ変更。
- 再生操作の常時表示、初回プレビュー対策、保存エンジンは維持。

## 確認
- 静的解析成功。範囲操作と暗幕追従を含む22件のテスト成功。
- 利用者がWindows画面を添付し「確認できた。OK」と回答。提示された画面で外観確認済み。
- 全画面サイズ・Android実機での外観を網羅的に確認したものではない。
- ハンドルは既存RangeSliderの丸形を維持し縦線を追加。参照画像の形状と完全一致ではない。
- 時刻入力は従来どおり表示専用。正確な切り出し境界へのスナップは未実装。
