# 次段階：1動画に複数区間（承認待ち）

## 1. 要件定義
- 目的：1本の長い動画から、複数の見どころを動画を開き直さずに切り出す。
- 対象：Windows / Android。複数動画一覧（ビルド10〜、確認済み）の各動画。
- 非対象：一括保存、結合、AI候補、タグ、区間のドラッグ並べ替え、再起動後の復元。
- 制約：保存エンジン・音声変換・原本は変更しない。新しい依存は追加しない。外部送信しない。
- 成功条件：動画Aに区間を3つ作る→動画Bへ切替→Aへ戻ると3区間とも保持され、選んだ区間だけを音声付きで保存できる。

## 2. 仕様
### 区間の一覧（範囲バーの直下）
- 横並びのチップ「区間1」「区間2」…と「＋区間を追加」を表示。狭い画面は横スクロール。
- 選択中の区間だけを既存の範囲バーと開始・終了の数値入力で編集する。
- 選択していない区間は、範囲バー上に薄い帯で表示する（操作はできない）。
- チップを選ぶと、その区間の開始位置で一時停止する。

### 追加
- 新しい区間は再生位置から5秒（動画の終わりで打ち切り）。
- 残りが0.1秒未満なら、終わりから5秒前を開始にする。5秒未満の動画は全体を指定する。
- 1動画につき最大20区間。上限では「＋区間を追加」を無効にし、理由を表示する。
- 追加した区間を自動で選択する。

### 削除
- 選択中の区間のチップのメニューから「この区間を削除」。確認ダイアログを表示する。
- 最後の1区間は削除できない（メニューを無効化）。
- 削除後は隣の区間を選択する（末尾なら前）。保存済みファイルは削除しない。

### 番号と重なり
- 番号は作成順。削除すると番号を詰める（区間2を消すと区間3が区間2になる）。
- 区間同士の重なりは許可する。警告は出さない。

### 保存
- ボタンは「この区間を保存」。選択中の区間だけを保存する。
- 保存結果は区間ごとに保持し、範囲を変えるとその区間の結果だけ消える。
- チップに保存済みの印（チェック）を表示する。

### 一覧の表示
- 各動画の2行目は「区間3 ・ 合計12.4秒」の形式。長さ未確認は従来通り「長さ未確認」。

### 初期状態
- 動画を初めて開いたときは、今と同じく全体を1区間とする。

## 3. 技術スタック
- Flutter / Dart。既存の media_kit・file_selector・保存処理を継続。

## 4. 設計
- `ClipSegment`：開始、終了、保存結果。
- `ClipItem`：`segments`（1〜20件）と `activeSegment`（添字）。旧 `startMs` / `endMs` / `output` は選択中区間を返す読み取り用にして、既存呼び出しの変更を小さくする。
- `ClipItem` のメソッド：`addSegment(positionMs)`、`removeSegment(index)`、`selectSegment(index)`、`setRange` は選択中区間に作用。`setDuration` は長さ外の区間を捨てず、全区間を範囲内に切り詰める（0.1秒未満になる区間だけ全体へ戻す）。
- `SegmentChips`：新しい部品。チップ表示、追加、削除メニューのコールバックのみ。
- `RangeTimeline`：`others`（他区間のリスト）を受け取り、薄い帯を描く。
- `main.dart`：区間切替は動画を開き直さず、範囲の差し替えとシークだけ行う。保存・読み込み中は追加・削除・切替を無効化する。
