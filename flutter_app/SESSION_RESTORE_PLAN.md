# 次段階：再起動後の復元

利用者の依頼「実機テストできるまでまとめて進めて」（2026-09-16）により、決めた点は既定案で実装し、ビルド13の実機確認時にあわせて確認してもらう。

## 1. 要件定義
- 目的：アプリを閉じても、動画一覧・区間・保存済みの印が次回起動時に戻り、続きから作業できる。
- 対象：Windows / Android。一覧の動画（順序）、動画ごとの長さ・区間・選択中の区間、区間ごとの保存結果、選択中の動画。
- 非対象：サムネイル・連続サムネイル（開いたときに作り直す）、再生位置、エラー表示、一括保存の途中再開、複数の作業を切り替える機能、クラウド同期。
- 制約：
  - 新しい依存を追加しない（path_provider を使わない）。外部送信しない。
  - 元動画・保存済み動画には触れない。作業記録はアプリ専用の場所にだけ書く。
  - 記録の書き込み途中で終了しても、前の記録が壊れない。
- 成功条件：動画3本・区間5個を作り1本を保存→アプリを完全に終了→起動すると同じ一覧・区間・チェック・選択中の動画が戻り、そのまま編集・保存できる。

## 2. 仕様
### 復元のしかた（決めた点1）
- 起動時に自動で復元する（「再開する／しない」は聞かない）。不要な動画は既存の「一覧から外す」で外す。
- 前回選んでいた動画を開く。元動画が見つからなければ、見つかる最初の動画を開く。1本も見つからなければ一覧と理由を表示する。
- 復元中は動画の追加を無効化する。

### 元動画が見つからない場合（決めた点2）
- 一覧には残し、エラー表示「元動画が見つかりません。移動・削除された可能性があります…」。区間の記録も残す。
- ファイルが変わって長さが短くなっていた場合は、開いたときに既存の処理で区間を切り詰める。
- Android のファイル選択で得たパスが一時領域のコピーだった場合、端末が削除すると見つからない扱いになる（実機で確認）。

### 保存済みの印（決めた点3）
- 前回の保存結果（パス／URI）をそのまま復元し、チェックを表示する。ファイルがまだあるかは確認しない。

### 記録するタイミング
- 画面の状態が変わるたびに、0.5秒待ってまとめて書く。アプリがバックグラウンドへ移る・閉じる直前にも書く。
- 書き込みに失敗したら、1回だけ「作業内容を記録できませんでした」と表示する。

### 記録の場所と形式（決めた点4）
- Windows：`%APPDATA%\kite_clipper\session.json`。Android：アプリ専用領域（filesDir）の `session.json`。
- UTF-8（BOMなし）、JSON、改行LF。形式バージョン1。
- `{version, savedAt, activePath, items:[{path, durationMs, activeSegment, segments:[{startMs, endMs, output}]}]}`
- 書き込み：`session.json.tmp` に書いてから置き換え。直前の記録を `session.json.bak` に残す。

### 壊れた記録
- 読めない `session.json` は削除せず `session.corrupt-<時刻>.json` に名前を変えて残し、`.bak` から復元して案内を出す。
- `.bak` も読めなければ空で始め、案内を出す。
- 動画1本分の記録が不正（区間が長さ外、区間数が20超、型違い、重複、31本目以降など）なら、その動画だけ読み飛ばし「読み込めなかった動画N本」と表示。
- 記録の場所自体が読めない等の想定外エラーでは、前回の記録を上書きしないよう今回は記録しない。

## 3. 技術スタック
- Flutter / Dart（dart:convert・dart:io）。Android は Kotlin で filesDir のパスを返すだけ。

## 4. 設計
- `ClipItem.restore(durationMs, segments, activeSegment)`：記録から区間を戻す。不正は ArgumentError。
- session_store.dart：
  - `encodeSession` / `decodeSession`（純Dart、動画単位の読み飛ばし、存在確認は関数で差し替え）。
  - `SessionStore`（場所の決定、一時ファイル経由の保存と .bak、壊れた記録の退避と .bak からの復元）。
- main.dart：起動時の `restoreSession`、`setState` 後の遅延保存、アプリ状態変化時の書き出し。`session` を差し替え可能にする。
- MainActivity.kt：`appDataDir` を追加。
- 一覧の「起動中のみ保持」の文言を「次回起動時に復元」へ変更。

## 6. 実機確認時に確認してほしい決めた点
1. 起動時に自動で復元する（聞かない）でよいか。
2. 元動画が見つからない動画も一覧に残す、でよいか。
3. 保存済みの印はファイルの存在を確認せずに戻す、でよいか。
4. 記録の場所（Windows は %APPDATA%\kite_clipper）でよいか。
